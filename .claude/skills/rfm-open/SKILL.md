# Open

Before your first reply, read the handover note, `[project]_handover.md`, and, if it exists, the working agreements, `[project]_working_agreements.md`, where `[project]` is the tag the project's document names start with. Both sit at the top level of the project's folder or documents unless the project names another place. If you can't find the note, search the project for a file whose name ends in `_handover.md` before saying it isn't there. Then load `rfm-unslop`, so it is in place from your first reply.

If the project has a git repository, run `git status` and keep the result for the close. Don't show it.

Then say in a few plain sentences where things stand: what we were doing, what we agreed to do next, and what was carried over. If what I brought touches something carried over, say so. Then say what you would start with, and turn to what I brought.
